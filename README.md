# lw1

# Паттерн Adapter
Реализован через шаблонный класс ShapeAdapter<T>. Адаптирует специфичные классы библиотеки SFML (sf::CircleShape, sf::RectangleShape, sf::ConvexShape) под единый абстрактный интерфейс IShape.

Высокоуровневая абстракция IShape не содержит зависимостей от графической библиотеки. При смене SFML на другой фреймворк потребуется изменить только класс адаптера.

# Паттерн Visitor
Реализован через интерфейс IShapeVisitor и класс SFMLDrawer. Используется для отрисовки фигур в графическом окне.
Позволяет выполнять операции над иерархией фигур без нарушения их инкапсуляции.

# Паттерн Factory
Реализован в классе ShapeFactory. Инкапсулирует логику создания конкретных объектов фигур (Circle, Rectangle, Triangle) на основе данных, полученных от парсера.

# Разделение ответственности
IShape, CPoint, Circle, Rectangle, Triangle - отвечают за математические расчеты и хранение геометрического состояния.

ShapeParser - разбор текстовых данных, 
ShapeFormatter - форматирование результатов в строку, 
ShapeManager - управление коллекцией фигур, чтение из файла и запись в файл.

SFMLDrawer - отвечает исключительно за отрисовку объектов SFML.

Application - связывает все модули. 

main - точка входа, делегирует управление классу Application.
